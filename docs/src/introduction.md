# Introduction

SemASM is multi-architecture semantic infrastructure for software written directly in assembly. It provides portable contracts, target kits, ASIR-based analysis, and verification pipelines. It does not replace assemblers or claim that assembly always beats optimizing compilers.

**Current status:** pre-1.0 developer line `v0.5.0`. Named owner CI jobs
exercise SysV, Win64, AArch64, and RV64 paths; maturity is defined only by
`capabilities.toml` (code present ≠ CI-proven support). Read the root
`README.md` for the claim boundary. The companion controller is VAA
`v0.2.0`.
